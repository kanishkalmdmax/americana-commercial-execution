# FieldDrive — Americana Riyadh van-sales pilot

Supervisor dashboard and salesman (VSR) mobile app in one self-contained file: `index.html`.
Open it directly or via GitHub Pages. All data is demo data and stays in your own browser.

- Build: `python build.py` (inlines `src/*.js` and `src/styles.css` into `index.html`)
- Tests: `node --test "tests/*.test.js"`
- Demo controls: press Ctrl + . (or add `?demo` to the URL on phones)

The previous version of this repository is on the `previous-main` branch.
